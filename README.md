# WAF
Agente de WhatsApp con IA para Ventas y Agendamiento

Agente conversacional que responde automáticamente a clientes por WhatsApp, agenda citas (llamadas o visitas) en Google Calendar, y está diseñado para escalar a un producto multi-cliente con herramientas conectables de forma incremental.

Objetivo del proyecto
Automatizar la atención inicial a clientes vía WhatsApp.
Agendar citas (llamadas / visitas) verificando disponibilidad real en Google Calendar, sin dobles reservas.
Servir, a mediano plazo, como plataforma que se pueda entregar a usuarios finales (multi-tenant), cada uno con su propio número de WhatsApp, su propio calendario y su propio set de herramientas activas.
Permitir añadir nuevas herramientas (CRM, pagos, inventario, etc.) de forma incremental sin reescribir la lógica central del agente.
